# Powerapps_gas

取得済みの架空ログを証跡用Excelへ転記し、環境・サーバーごとの転記・反映状況、担当者の確認、レビュアーへの引き継ぎを扱う、転職活動向けの動くポートフォリオを目指す。Power AutomateとPower Appsを使い、Excel関数は作品に含めない。

要件本文と4画面の設計は承認済み。技術上の規律、実装計画、確認方法は草案で、方式検証・アプリ実装・公開は未実施。現在の判断と未決定事項は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)、進捗は [docs/TASKS.md](docs/TASKS.md) を参照する。
