# Powerapps_gas

取得済みの架空ログを証跡用Excelへ転記し、環境・サーバーごとの転記・反映状況、担当者の確認、レビュアーへの引き継ぎを扱う、転職活動向けの動くポートフォリオを目指す。Power AutomateとPower Appsを使い、Excel関数は作品に含めない。

要件本文と4画面の設計は承認済み。技術上の規律、実装計画、確認方法は草案。Developer環境の非公開Power Appsに4画面と件別転記フローを接続し、架空ログの保存・処理開始・Excelの実内容照合・担当者確認・レビューを部分的に実機確認した。異なる環境の正常2件は1回の開始操作で件ごとにExcelが1冊ずつ作られ、識別情報とログ全文が一致した。日付不一致の件だけを止め、同時開始した正常件は完了した。初版で結果不明になった旧Bは保全し、再実行していない。入力異常の残りの種類、保存先側の失敗と安全な再実行、長文、レビューの残る分岐は未確認で、アプリは未公開。現在の判断と未決定事項は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)、条件別の結果は [docs/TASKS.md](docs/TASKS.md)、確認方法は [docs/CHECKS.md](docs/CHECKS.md) を参照する。
