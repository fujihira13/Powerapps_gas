# MQ ID照合用の架空サンプル

このフォルダーには、MQ ID照合の形式確認に使う架空データを置いています。実務データと個人情報は含みません。

| 件数 | バッチ入力Excel | 実行ログ | 照合の想定 |
| --- | --- | --- | --- |
| 5件 | mq-id-5-items-20260927.xlsx | mq-id-5-items-20260927.txt | 予定5件、ログ記録4件、欠落MQ-0003 |
| 100件 | mq-id-100-items-20260927.xlsx | mq-id-100-items-20260927.txt | 予定100件、ログ記録100件、欠落MQ-0050、ログのみMQ-9001 |

## 共通形式

- ExcelはBatch_Inputシート1枚です。A1はMQ Batch Input、A2はMQ_ID、A3以降は予定IDを1列に1件ずつ記録しています。
- ログ冒頭の4項目は処理日、環境、サーバー、実行回です。その後に英語のノイズ行と、行頭からMQ_BOX_ID=MQ-0001形式で始まるID行を置いています。
- ログの最終行はALL SUCCESSです。これはログ出力の終了を示し、すべてのIDの反映成功を示しません。ID記録は行頭MQ_BOX_IDの行だけで数えます。

## 識別項目

- 5件版: 処理日2026-09-27、架空環境A、架空サーバーA、実行回92701。
- 100件版: 処理日2026-09-27、架空環境A、架空サーバーA、実行回92702。
- 5件版の予定IDはMQ-0001〜MQ-0005です。ログにはMQ-0003の行頭ID記録がありません。
- 100件版の予定IDはMQ-0001〜MQ-0100です。ログにはMQ-0050の行頭ID記録がなく、予定外のMQ-9001を記録しています。
