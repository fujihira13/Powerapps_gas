## 共通形式

- ExcelはBatch_Inputシート1枚です。A1はMQ Batch Input、A2はMQ_ID、A3以降は予定IDを1列に1件ずつ記録しています。
- 新しいログは冒頭3行に処理日、環境、サーバーを置きます。その後に英語のノイズ行と、行頭からMQ_BOX_ID=MQ-0001形式で始まるID行を置いています。旧見本には4行目の実行回が残りますが、新しい受付では入力・照合しません。
- ログの最終行はALL SUCCESSです。これはログ出力の終了を示し、すべてのIDの反映成功を示しません。ID記録は行頭MQ_BOX_IDの行だけで数えます。
