# サーバー一覧切替の見える結果

## 承認・目的

2026-10-03、「サーバーを見る」を押すと対象一覧が見える位置へ移動し、見出しを「環境Aのサーバー」の形にする具体案に対する「お願いします」を実行承認として扱う。既存のDeveloper非公開アプリへの画面送信・検査・保存・読戻しの承認範囲内。公開、登録変更、照合実行、通知、削除なし。

## 対象と変更方法

- 対象はScreen5のみ。App・受付・進捗一覧・確認・レビュー、データ、フローは変更しない。
- Studioを開き直してCanvas MCPを再接続し、最新7定義を別フォルダーへ同期・保全する。ローカル既存変更を上書きしない。
- 現行GroupContainer内にはSetFocusを使えないため、管理画面の最外周スクロールだけを標準のFluidGridとBlankCardへ置き換える。中央幅1200px、760pxの左右／上下境界、各パネル・登録枠・操作・全体スクロールを保持する。
- 現行の環境名表示をスクロール用カード直下へ移し、位置は既存サーバーパネルの環境名表示位置に合わせる。Textは実登録名＋「のサーバー」、未選択時は「サーバー」。同じ位置で表示するため、説明行を追加しない。
- ボタンの既存所属一覧切替にSetFocusを追加し、この見出しへ焦点と表示位置を移す。使用中タブへ戻す既存動作は保持。未選択・使用終了親・空一覧の既存制御は維持する。
- 実装候補はoutputs/environment-management-20261003/server-navigation/candidate、変更前はbaseline。未保存候補に問題があればbaselineを再検査・反映して戻す。構造上の位置関係と既存イベントの不変を比較して確認する。

## 確認・順序

1. 対応するコントロールの公式定義を読み、候補を限定変更する。サブエージェントなし（承認済みユーザー方針を継続）。
2. 画面7定義を構文検査し、エラーを解消する。
3. 実プレビューの通常幅で環境A→B、下方の環境から一覧が見える位置への移動、長い環境名を確認。
4. 電話390pxで環境一覧→サーバー見出しと一覧が画面内に現れること、全体スクロール・編集キャンセル・戻るを確認。データを書き込む確定操作は実行しない。
5. 非公開保存、保存後同期、候補との差と他画面不変を比較。保存版Screen5だけをcanvas/currentへ反映し、資料へ実施結果を追記する。

見た目と焦点移動の修正なので、新しい照合テストや保存処理のテストは作らず、実画面で表示位置・操作結果を検証する。費用・接続・権限の追加なし。登録・照合・通知の増加は0。

## 実施結果（2026-10-03）

- 最新7定義を保全。候補7定義の検査合格。Screen5以外の6定義は意味上不変。
- スクロール部品の差し替え直後、Studioに古い内部参照が残り、画面再描画／プレビューのNamedObjectNotFoundが発生。変更前への復帰を挟み、管理画面部品を一時空のScreen5から同じ候補へ再構成し、再読込後に解消した。保存処理・データ変更なし。これは失敗と復旧の履歴であり、最初の検査成功を実表示成功とは扱わない。
- 通常幅で環境Bの所属サーバー表示、最下行の動作確認環境への切替と見出しへの焦点移動を確認。最下行クリック後にスクロール位置0、見出しY263.64pxが画面内。所属サーバー2つを表示。
- 電話390pxでは上下配置を保ち、環境Bのボタン後に標準スクロールが2248pxへ移動、見出しY337.84px、サーバー一覧Y419.11pxが画面内。焦点移動はイベント直後の短い非同期描画を経て完了する。スマホ専用版の作成ではなく一時的な狭幅検証。
- PCのウィンドウサイズへ復帰。サーバーBの名称変更入力の初期値が架空サーバーB、キャンセル後に元名を表示。進捗一覧への戻りを確認。
- Studioの「保存済み: 2026/10/3 14:58:58」を確認。再読込後の7定義は候補一致（X/Y=0の既定値省略3箇所以外）。保存版Screen5だけをcanvas/currentへ反映。生成スクリプトも同じ移動処理を使う。
