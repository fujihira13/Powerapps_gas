# 受付の空白と進捗の経過時間表示を修正

## 目的・範囲

ユーザーが確認した二つの不具合だけを直す。SCR-01では環境・サーバー・対象処理日の必須入力が幅0で見えず、フォームの上に空白が残る。SCR-02では経過時間の表示更新が10秒ごとのデータ再読込と結合している。既存の保存・照合・レビュー・保管のロジック、文言、フロー、表、Excelは変えない。

## 変更順序

1. Canvas Authoringから6ファイルを新しいローカル保存先に同期し、変更前の状態を保全する。
2. Screen1の見える必須3カードに画面幅に応じた幅を設定する。警告文が空のときはその高さを受付フォームの開始位置に加えず、Excelとログの欄を必須項目の直後に置く。警告文があるときは表示を保つ。
3. Screen2の表示用タイマーを約1秒間隔にし、Dataverseの再読込は別の10秒タイマーに移す。非表示タブではブラウザーによるタイマー制限があり得るため、復帰時は現在時刻から経過時間を計算する。
4. Canvasの構文検査、非公開Studioへの保存、保存後の定義読戻し、SCR-01とSCR-02の最小画面確認を行う。新しい件や添付は作らない。

## 完成条件・戻し方

- SCR-01で環境・サーバー・対象処理日が見え、日付を変更でき、添付欄まで不自然な空白がない。警告文が必要な場合は読める。
- SCR-02で表示用時刻は約1秒ごとに更新され、データ再読込は10秒ごとに分離される。実処理中の視覚確認ができない場合は未確認と報告する。
- 構文検査が通り、非公開Studioで保存した定義を読戻せる。問題があれば変更前同期ファイルを使い、既存データを触らず修正する。

外部送信は既存アプリのPower Apps編集サービスにCanvas定義を送る操作に限る。公開・新規テストデータ・フロー変更は含まない。2026-09-29のユーザーによる具体案への「修正してください」を本計画の承認として扱う。
