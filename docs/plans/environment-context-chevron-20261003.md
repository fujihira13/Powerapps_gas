# 管理対象の環境表示と受付の矢印修正

## 承認と範囲

ユーザーの「そうですねそうしてほしいです。また、左のUIが崩れています」に基づく限定修正。既存のDeveloper環境への画面定義送信・検査・非公開保存・画面操作確認の承認範囲内で実施する。サブエージェントは使用しない。

## 実装内容と順序

1. 現行7定義を同期し、変更前を保全する。
2. Screen5のlblM05EnvContextを「対象の環境：{登録名}」へ変更する。サーバー見出し、一覧切替、焦点移動を保持し、生成用処理の文言も更新する。
3. Screen1のenvS01Arrowの文字「⌄」を空にし、白い標準ChevronDownアイコンを重ねる。青い背景と既存ボタンを保持し、アイコンのクリックもenvS01Fieldへ接続する。20px四方の矢印を34px幅のボタン内へ上下左右中央配置する。
4. 7定義を検査・反映し、PCプレビューで矢印の中央位置、候補開閉、環境Bへの変更と所属サーバー切替、管理画面の対象環境表示を確認する。
5. 非公開保存後に読み戻し、変更範囲を照合して現行ソースと記録を更新する。

## 合格条件

対象環境が明示され、矢印が中央に表示される。環境選択とサーバー候補更新は従来どおり動く。構文検査と保存後の読み戻しが一致する。照合実行・データ変更・通知・公開・削除は行わない。

## 実施結果

7定義検査合格。PCプレビューで環境矢印は20×20px、背景ボタン34×40pxに対して左右7px・上下10pxの中央位置をDOMで確認。白い標準ChevronDownを使用。アイコンのクリックで環境候補が開き、環境B選択後に候補が閉じてサーバーBへ切り替わった。管理画面は「対象の環境：架空環境B」、所属一覧は架空サーバーB。焦点移動後の見出しは画面内に表示された。
