# 環境選択欄のホバー色

「通常は白背景・濃い文字、ホバー時は青背景・白文字、離すと通常色」の具体案への修正依頼により承認済み。

対象はScreen1の環境ドロップダウンDataCardValue2のHoverFill／HoverColorだけ。背景RGBA(16,110,190,1)、文字RGBA(255,255,255,1)。通常色・押下色・選択候補・選択値・保存と照合・サーバー欄は変更しない。

最新6定義を同期・保全→2プロパティだけ変更と差分確認→既存のPower Apps編集サービスへ検査→非公開Studio保存→6定義読戻し一致→環境欄の表示を確認。サブエージェント・大規模試験・公開・新規照合・添付保存・通知・削除なし。外部コード送信と保存の具体承認を引き継ぐ。追加費用・権限なし。失敗時は今回2プロパティだけ元へ戻す。

## 結果

2プロパティのみ変更、6定義検査合格、Studio保存・読戻し一致。プレビューでホバー時の青背景・白文字、欄外へ移した際の通常色への復帰を実表示確認。選択値は環境Dのまま、クラウド保存・照合は未実行。
