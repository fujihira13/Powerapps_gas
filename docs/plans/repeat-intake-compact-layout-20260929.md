# 同じファイル名の再照合と受付画面の余白を修正

## 承認済みの目的

2026-09-29の会話で、同じExcel・ログを意図して何度も照合できること、過去件のファイル名検索・警告で新しい受付を止めないこと、PC画面の大きな空白を減らすことが承認された。照合そのものの判定、保存読戻し、同一クリックの連打抑止、結果不明時の再送禁止は保つ。

## 対象と変更

- `outputs/canvas-repeat-layout-20260929/Screen1.pa.yaml` のみ変更する。その他のCanvas画面、Dataverse、フロー、Excel、既存件は変更しない。
- 「照合を開始」は入力2ファイル・環境・サーバー・日付を確認したら、新しい件を1つ保存する。以前のファイル名を調べる3データソース照会、同名警告、照会不能による停止、確認用ボタンを取り除く。各受付は既存の件GUIDと受付日時で区別する。同じ受付の保存中・開始中・結果不明中は既存の抑止を維持する。
- 入力不足・拡張子違いの案内は残す。警告欄の高さは文言がないとき0、文言があるとき必要な分だけにする。フォームの固定余白を少し縮め、PC幅ではExcelとログの添付欄を横並びにし、その直下に開始ボタンと状態を置く。狭い画面では添付欄を縦に並べる。

## 確認と戻し方

最新定義を別ディレクトリへ同期して変更前を保全する。6ファイルのCanvas構文検査、非公開Studio保存、保存後の定義読戻しを確認する。プレビューで通常状態と添付・入力欄・ボタンの位置を確認する。新しい件は作らず、同名ファイルを使った実際の保存・処理は次回の通常操作時に確認する。問題が出た場合は変更前の同期定義から差分を確認して修正する。公開、削除、追加費用、実務データ利用は含めない。
