# 環境選択欄の状態色を分ける

ユーザーが具体案へ「じゃあそれでいきましょう。修正しといてください」と実行承認。

入力欄のホバーと選択済み候補は薄い青／濃い文字、候補のホバーは濃い青／白文字を目標とする。最初にClassic/DropDownの標準プロパティを確認し、HoverFill／HoverColor／SelectionFill／SelectionColorを調整して実表示を確認する。表示色と文字色の4プロパティのみを候補にする。選択値・候補・環境によるサーバー絞込み・保存・照合は維持。

最新6定義保全→状態別の色変更→構文検査→Studioで候補の実表示確認→達成したものだけ非公開保存・読戻し→canvas/currentと仕様・結果を更新。標準部品で候補ホバーと選択済みを独立設定できない場合、黙って同色にすることや保存式の改造はしない。必要な表示部品の置換について具体的な影響を説明する。承認済み外部コード送信とStudio保存を引き継ぎ、公開・削除・新規照合・通知・購入なし。ユーザー指示によりサブエージェント・大規模試験なし。失敗時は今回の色だけ戻す。

## 標準部品の確認と採用方式

標準DropDownは入力欄／候補ホバーのHoverFillが共通で、4色の調整では候補も薄くなることを実表示確認。単一選択ComboBoxの候補も同色で、不要な選択タグ／削除操作が出るため採用せず、候補は未保存のまま破棄。

Screen1内で表示だけを分ける。元の標準欄のItems／Selected.Valueと保存式の意味を保持して標準欄を非表示にし、同じ位置の入力表示ボタンと矢印、画面直下の候補Galleryを配置する。候補クリックはThisItem.Value（元の環境保存値）をUI用varS01EnvChoiceへセットし、元選択欄Defaultへ表示名に変換して反映する。新規受付時の既存ResetForm前に選択変数を空へ戻す。OnVisibleで候補を閉じ、欄外クリックでも閉じる。入力欄は通常白・ホバー／候補展開中薄青、選択済み行は薄青、候補のホバー／押下は濃青・白文字。単一選択、環境→サーバー絞込み、元の必須条件を維持。候補の高さを画面内へ制限して多い場合は一覧だけスクロール。マウスとTab／Enterで操作する。

必要な最小確認は3状態の色、同じ環境を選ぶ、別環境を選ぶと対応サーバーへ切り替わる、欄外クリック閉じ、新規受付で初期値に戻る、Tab選択、他5定義／保存・照合ハンドラー不変。照合開始やクラウド保存は行わない。保存前6定義への復旧が可能。具体的な表示案への実装承認内の表示部品変更として実施する。

部品型の試行後、旧名DataCardValue2への参照が初期値を返す状態を確認したため、標準欄をenvS01ValueBridgeへ改名しScreen1内の参照先だけを変更した。元の生の環境値を保存する意味は維持。改名後に環境A／サーバーAの表示が復旧。候補の重なりはStudioの再配列で欄外クリック用ボタンを最前面、その後候補一覧を最前面へ移動して修正した。保存後のYAMLは末尾が前面で、既存画面→欄外クリック用ボタン→候補一覧の順。新規保存や照合は実行しない。
