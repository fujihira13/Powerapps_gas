## 保存契約

操作は環境追加・サーバー追加・環境名称変更・サーバー名称変更・環境使用終了・環境再使用・サーバー使用終了・サーバー再使用の8種類。削除操作は追加しない。

- 空欄、100文字超過、使用終了行を含む重複を保存前にもサーバーで拒否。
- 環境の変更は表示時の対象全行IDと版を再取得値と照合。行の追加・消失・版の変更を検出したら上書きしない。
- 競合文言：「登録内容が変更されています。読み直してから操作してください。」
- サーバー追加・再使用は環境が使用中であることを保存時にも確認。
- 追加は現在の共通保存先設定を引継ぎ、利用確認失敗では作成しない。設定自体が確認中に変わった場合も作成しない。
- 更新対象には楽観的同時実行チェックを適用。全対象を同期トランザクションに含める。Canvasの行別Patchで一括保存を代用しない。
- 保存後の実際の登録名・状態・対象ID・版を返し、画面をそれに基づいて更新する。通知だけで成功扱いしない。

- 環境名称変更：見出し「環境名を『{変更前}』から『{変更後}』に変更しますか？」、本文「ログに書かれている環境名も『{変更後}』になっていることを確認してください。」。実表示の括弧は「」を使う。
