# 余白・未保存表示の修正とテストデータ整理

## 承認と範囲
2026-10-01のユーザーの実行依頼による。非公開アプリのScreen1とScreen3の表示だけ修正する。削除は候補を報告して個別承認を得るまで実行しない。既承認のCanvas送信・保存・表示確認の範囲を引き継ぐ。新規照合・依頼確定・通知送信・公開なし。

## 具体的な手順
1. 件表、件別ファイル表、両表に結び付く添付だけを読み、GUIDで関連を確認する。OneDriveの結果とSharePointの3ファイルフォルダーを照合する。ローカルの見本と出力を列挙する。ひな形・設定・検査用見本は削除候補から外す。
2. MCP接続が422で失敗しており同期は不可。Studioの実画面とコード表示で最新状態を保全し、表示のプロパティを対象限定で修正する。既存保存・照合式、標準フォーム内添付、最大1ファイル制限は変えない。
3. 標準添付欄に未保存表示を消す公開プロパティがないため、選択済みの表示をファイル名ラベルへ置き換え、実添付欄はフォーム内に維持する。変更・削除は従来のResetで選択だけ解除する。未添付時の余白は位置と高さを調整して詰める。
4. Screen3右列の開始位置を上へ寄せ、依存して配置されるファイル・リンク・担当者欄も追従させる。全体スクロールと確認ダイアログは保持する。
5. 最低限の実画面確認（空、片方、両方、変更・削除、結果画面の最下部）を行いStudio保存する。別のMCPセッションへ古い定義を送らない。実画面コードを保全する。
6. 日付なしの新しい差異なし・あり各1組をローカルへ作り、6 ID一致と1 ID不足を内容で確認する。クラウド照合はユーザーが行う。
7. 削除候補一覧、残すもの、復元可否、未確認を報告する。このターンでは削除しない。

## 戻し方・完成条件
変更前の対象画面コードを保全。表示不良時は対象プロパティのみ元へ戻す。未保存表示なし、見出し直下に添付操作、右上の余白縮小、下部へスクロール可が完成条件。データ・処理条件の変更なし。新規費用・権限が必要な操作は含めない。ユーザー指定によりサブエージェント・大規模試験を行わない。
