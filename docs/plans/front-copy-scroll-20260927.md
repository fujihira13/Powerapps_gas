# 画面文言とスクロールの修正

## 対象

非公開 Canvas アプリの受付、進捗一覧、ログと結果の確認、レビューの表示のみ。既存の保存、転記、担当者確認、レビュー操作は維持する。表、フロー、登録済みデータ、公開設定は変更しない。

## 変更

1. 進捗一覧の操作名を「新しいログを登録」「ログと結果を見る」にする。
2. 確認画面名を「ログと結果の確認」にする。ログのみの件では MQ 固有の見出し、件数、説明、ID 一覧を出さない。結果 Excel の状態は残す。
3. 添付 2 件が同時に見える高さにし、MQ ID 一覧の表示領域を拡げて一覧内でスクロールできるようにする。画面全体を単一スクロールにする変更はプレビューで表示が崩れたため採用していない。
4. 環境とサーバーの表示から先頭の「架空」を除く。受付選択時は保存値を従来のままとする。

## 確認

Canvas 構文検査、Studio の保存完了表示、プレビューでログのみと MQ 件の表示、添付 2 件と MQ ID 一覧、受付の環境・サーバー候補を確認する。新規件の保存や処理開始は行わない。大量の ID に対する一覧内スクロールは実データで未確認。

## 2026-09-27 の反映結果

- 非公開 Studio で保存済み表示を確認。画面定義6ファイルの `compile_canvas` は合格。公開はしていない。
- 進捗一覧のボタン名、確認画面の見出し、表示上の環境・サーバー名をプレビューで確認した。受付の選択肢は環境A～Hなど、先頭の「架空」がない表示を確認した。
- ログのみの既存件ではMQ固有の説明・ID一覧が出ず、結果Excelの反映状態が残ることを確認した。MQ件では `.txt` と `.xlsx` の両方、5 IDの結果と欠落 `MQ-0003` を確認した。
- 画面全体の単一スクロールは未実現。現在はMQ結果一覧内のスクロールで長いID列を読む構成。5 IDの表示は確認済みだが、約100 IDで末尾まで操作できるかは未確認。
