## 2026-10-02 最新：レビュー依頼の確認文

依頼確認のダイアログは「レビューを依頼しますか？」と「キャンセル／依頼する」だけ。依頼対象のファイル名は表示しない。対象件は内部のGUIDで保持し、依頼条件と保存読戻しは変更しない。確認ダイアログへのファイル名表示を指定した旧記述は本節で置き換える。

実演役割の表示・切替を除去。依頼中／再依頼は同じ確認画面で直接「承認／差し戻し」を選び「レビューを完了」で保存する。差し戻し理由必須。未依頼／差し戻しの担当者判断・コメントは入力可能、依頼後は通常色の読取専用表示、完了後はレビュー結果を表示する。GUID・版・依頼状態・元2ファイル・処理完了・Excel読戻し・連打抑止は維持。以前の役割切替を必須とする記述は本節で置き換える。現在の1アカウント構成であり、別人のアクセス制御は未追加。

## 2026-10-02 最新：同じ画面で証跡確認とレビュー

元Excel・元ログ・照合結果・差異IDの配置と10件ページ切替を保持し、右列に担当者判断・コメントとレビュー操作を続けて置く。全体のスクロール下端は新しい操作・理由・エラーまで含める。

| 状態 | 担当者欄 | レビュー操作と保存後表示 |
| --- | --- | --- |
| 空／未依頼 | 一判断とコメントを編集、下書き・依頼確認は既存どおり | レビュー入力なし。未依頼文は非表示 |
| 依頼中／再依頼 | 通常色の読取専用判断・コメント | 実演役割切替、承認／差し戻し。レビュアー役だけ記録可。差し戻しは理由必須 |
| 確認済み | 読取専用 | レビュー結果：承認、入力・再記録なし |
| 差し戻し | 担当者の修正・再依頼が可能 | レビュー結果：差し戻しと保存理由を参照 |

保存は既存件GUID・版・依頼状態・ファイル2件・処理完了・Excel反映全文一致を再確認して、レビュー状態と理由だけ更新する。承認→確認済み、差し戻し→差し戻し。両値の読戻し成功後に同じ画面で保存結果表示へ切り替える。失敗・結果不明は赤いエラーと開き直しの案内、連打と無条件再送を抑止する。戻るは矢印なし左上「進捗一覧に戻る」、保存／依頼確認中は無効。戻る時と保存後に担当者役へ戻す。役割は従来の1アカウント実演であり、別利用者の権限認証ではない。レビュー確定時は既存Teamsフローの通知対象になる。
