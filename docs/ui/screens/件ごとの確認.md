## 画面の役割整理案

| 項目 | 内容 |
| --- | --- |
| 目的 | 1件のログと証跡Excelの転記内容を照合し、それとは別にログに記された処理結果について担当者の判断を記録する。失敗件の安全な再実行も件別に扱う。 |
| 主操作 | 架空ログと対応する証跡Excelを参照して転記内容を確認する。処理結果を「正常・異常・判断保留」から判断し、コメントを記録する。確認が整った件をアプリ内でレビュー依頼する。 |
| 補助操作 | 失敗件について状態と過去の証跡を確認し、重複や消失を防げる条件が整った場合にその件だけ再実行する。差し戻し後は必要な修正と再依頼へ進む。修正対象・操作の詳細は未決定。 |
| 必要な情報 | 件の識別情報（環境・サーバー・実行回・対象処理日）、ログと対応するExcelへの参照、転記内容の照合結果、実反映の確認状態、担当者の処理結果判断とコメント、失敗理由、レビュー依頼状態。 |
| この役割には不要な情報 | 全件の全文を同時に並べる表示、別件の修正・再実行、Excel関数の結果、アプリによるバッチ処理の成否の自動断定。 |
| 入口 | 進捗一覧から対象件を選んだとき。差し戻し後にその件を見直すときの入口も候補。 |
| 出口 | 確認・再実行の後に進捗一覧へ戻る案。レビュー依頼後はレビューの役割へつなぐが、担当者役からレビュアー役への切替位置は未決定。 |

## 境界と未決定

- 転記内容の一致確認と「正常・異常・判断保留」の人による判断は別々に記録する。アプリが実際のバッチ処理の成否を断定しない。
- 失敗件の再実行は、状態確認前に自動で同じ内容を転記しない。既存Excelの扱いと二重転記防止の具体方式はT-004と技術検証で決める。
- 受付の参考画像B案はこの画面の参考画像ではない。**この画面の参考画像・承認済み基準画像・対応テストは未作成**。ボタン名、コメント形式、転記照合の表示方法は未決定。
