## 画面の役割整理案

| 項目 | 内容 |
| --- | --- |
| 目的 | レビュー依頼された件について担当者の確認結果を見て、レビュアー役の確認済みまたは理由付き差し戻しを記録する。 |
| 主操作 | 依頼された件と担当者の転記照合・処理結果判断を確認し、確認済みまたは差し戻し理由を記録する。差し戻し後の修正・再依頼を追えるようにする。 |
| 補助操作 | 対象件の詳細を見直す場合は件ごとの確認へつなぐ案。レビュアー役への切替の操作方法と場所は未決定。 |
| 必要な情報 | 依頼された件を識別する情報、担当者の確認結果と判断・コメント、レビュー依頼状態、レビュアー役の確認結果、差し戻し理由、再依頼の状態。 |
| この役割には不要な情報 | 新しいログの受付、Excelへの転記開始、失敗件の再実行、メール・Teams通知の操作。これらをレビューの主操作として加えない。 |
| 入口 | 担当者役がアプリ内でレビューを依頼した件を、レビュアー役として確認するとき。進捗一覧から依頼状態を見て入る導線は候補。 |
| 出口 | 確認済み・差し戻しを記録した後に進捗一覧へ戻る案。差し戻しの修正は件ごとの確認へつなぎ、修正後の再依頼を扱う。細かな遷移は未決定。 |
