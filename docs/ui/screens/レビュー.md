## 処理と遷移

- **確定**：アプリ内でレビュー依頼・確認済み・理由付き差し戻し・修正後の再依頼を扱い、状態を一覧で確認できる。実演は1アカウントの二役で、別人レビューや権限制御の証明としない。
- **未決定**：役割切替の場所と操作、レビュアーの確認基準、理由欄の制限、未保存時、結果の訂正方法、成功・失敗時の正確な表示と遷移。推奨は依頼と結果の保存が確定するまで一覧へ成功表示を出さないこと。

## 使いやすさ

- どの件をレビューしているか、担当者の照合と人の判断、レビュアーの結果を分けて示す。差し戻し理由を当該件に結び付ける。
- 1アカウントの役割切替を実際の権限制御と誤認させない。結果保存に失敗した場合も確認済みと見せない。

## 変更の境界

- **固定する意味**：依頼、確認済み、理由付き差し戻し、修正後の再依頼、一覧への結果反映、1アカウント実演の限界。
- **承認待ち**：役割切替、確認基準、理由入力の形式・制限、ボタン・状態の文言、入力初期値、訂正方法、遷移。上表の推奨案は承認済み要件へ昇格させない。
- **初回実装で改善可能な見た目**：余白・整列・文字サイズ・コントラスト・境界線・長い理由の読みやすさ。機能・入力・文言・状態・遷移の追加変更、仕様外の説明文・見出し・ボタンは禁止。
