## 処理と遷移

- **確定**：1件が止まっても独立件は続く。Excelへの書込処理の完了と実際の反映確認は別。結果不明を「反映済み」と表示しない。開始後の進行中取消を置かない。
- **未決定**：状態名、表示更新の契機、反映確認の方法、再実行の可否と条件、画面間の細かな遷移。推奨は件別の根拠が揃うまでは成功表示・再実行を行わないこと。

## 使いやすさ

- 保存、転記処理、Excel実反映、担当者確認、レビューを別の列やまとまりで示し、1つの「完了」にまとめない。失敗理由と該当件の対応を明確にする。
- 一覧から対象件へ進めるようにし、全文を常時詰め込まない。色だけで状態を区別しない。

## 変更の境界

- **固定する意味**：件別進捗、失敗理由、書込処理と実反映の区別、独立件の継続、結果不明の非反映済み扱い、担当者・レビュー状態の表示。
- **承認待ち**：状態名・正確な文言、表示更新条件、行の操作、役割切替、遷移。上表の推奨案を画像や要件の確定内容として扱わない。
- **初回実装で改善可能な見た目**：余白・整列・列幅・文字サイズ・コントラスト・境界線・画面幅への収まり。項目・ボタン・意味・遷移の追加変更は含めない。仕様外の説明文・見出し・ボタンは追加禁止。
