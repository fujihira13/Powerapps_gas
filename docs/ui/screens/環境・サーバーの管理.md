# 環境・サーバーの管理

## 2026-10-03 現行：サーバー中心の管理を非公開反映

全環境入力ラベルは「対象の環境名」。サーバー追加はサーバー名＋対象の環境名、環境追加は「{サーバー名}に環境を追加」で対象を示して環境名だけ入力する。常設ヒント・選択中・成功結果・青い選択枠は表示しない。

実運用はサーバーを親、環境を子とする。PCは左「サーバー」一覧／右「{サーバー名}の環境」一覧、最大1200px中央。760px以下はサーバーの下に環境。環境を見るで右一覧切替と見出しへの焦点・表示移動を行う。両者とも名前は普通の文字、変更／終了／再使用は各枠内。サーバー操作は所属全環境の親設定へ適用、環境操作は1行のみ。終了したサーバーで環境の追加・再使用を無効化する。

[詳細計画と確認結果](../../plans/server-first-management-20261003.md)。Screen5・同期保存・管理エラー応答を非公開反映。PC実表示と新規サーバー1つ／環境2つの保存、終了保持、重複・古い版・旧画面拒否を確認。電話表示は今回実機確認せず、狭幅の構造式のみ確認。ユーザー実物受入・基準画像は未実施。以下の逆の関係は当時の実装履歴であり、現行仕様には適用しない。

## 配置・操作

### 2026-10-03 最新：サーバーを見る操作の結果を画面内へ表示

ユーザーの「お願いします」で変更承認。「サーバーを見る」は所属一覧を切り替えた後、その環境の見出しへ焦点を移し、画面外にある場合は一覧が見える位置まで標準スクロールする。以前の「選択した環境：{名}」は「{実登録の環境名}のサーバー」へ変更。未選択時は「サーバー」。独立した説明行は追加しない。名前のクリック・青い選択枠・「選択中」は追加しない。

全体スクロールをFluidGrid／BlankCardに変更し、見出しをカード直下へ置くことでSetFocusを利用する。幅1200px中央／760px境界の左右・上下、各登録の管理操作を保持。PC通常幅と電話390pxで見出し・所属一覧が画面内に現れること、編集キャンセル・戻るを確認。電話は一時検証で終了時にPCへ戻した。非公開保存・再読込一致。詳細と途中の失敗・復旧は[限定修正計画](../../plans/server-list-navigation-20261003.md)。以下の「選択した環境」やGroupContainerに関する古い表記は変更前の履歴。

進捗一覧上部「環境・サーバーを管理」から開く。左上の戻るは既存と同じ「進捗一覧に戻る」、矢印なし。管理内容全体は最大1,200px中央。広い画面は左環境／右選択環境のサーバー、狭い画面は上下。全体をスクロールでき、一覧やボタンが見切れて操作不能にならない。

2026-10-03の追加指示でHTML見本を更新。表示幅760px超は左右、760px以下は上下。環境側の一覧切替は「使用中の環境／使用終了した環境」、サーバー側は「使用中のサーバー／使用終了したサーバー」。各登録の右側に重複する「使用中」は置かない。

環境の枠内の「サーバーを見る」で所属サーバーを更新。環境とサーバーの名前は通常の文字で表示し、枠や名前のクリック選択・青い選択枠は用意しない。名称変更・使用終了・再使用は各登録の枠内へ置き、その行の登録を直接対象にする。一覧末尾の共通操作ボタンは除く。名称変更欄にはその行の実際の保存名を初期表示。旧名の自動読み替えはしない。環境とサーバーの追加はそれぞれの一覧上部。

2026-10-03の追加承認により、上記の枠内操作をHTMLへ反映。「選択中」の文字は除去済み。追加・名称変更欄の「ログに記載される実際の名称を入力してください。」も除去。環境の終了確認は「{環境名}を使用終了にしますか？ この環境のサーバーは使用できなくなります。」、サーバーは「{サーバー名}を使用終了にしますか？ 使用できなくなります。」。環境Bのサーバー表示切替、環境／サーバーの名称変更欄、環境終了確認とキャンセルをin-appブラウザーのDOMで確認。画像は新規作成していない。実Canvasへの反映は未実施。

環境追加は環境名＋最初のサーバー名、サーバー追加は選択中環境＋サーバー名。入力欄の近くに空欄・文字数・重複理由を表示。保存中は連打を防ぎキャンセルしない。保存前のキャンセルでは変更しない。成功時は読戻した登録名と状態を画面へ反映。

最新承認の名称変更確認：見出しは「環境名を『{変更前}』から『{変更後}』に変更しますか？」、本文は「ログに書かれている環境名も『{変更後}』になっていることを確認してください。」。実表示の括弧は「」を使う。サーバー変更では「環境名」を「サーバー名」に置換。変更前は対象行の現在名、変更後は入力検証後の変更名。共通の旧名称警告は置かない。「キャンセル／変更する」は維持。画面下の操作結果表示 `#receipt` は除去し、追加・変更・使用終了・再使用の結果は一覧へ反映する。

環境の使用終了は受付で所属サーバーを選べなくする。個別サーバーの使用状態を変更せず、再使用時に個別終了サーバーを復活させない。終了環境へのサーバー追加・再使用は環境の再使用後に行う。
